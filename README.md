# Portfolio

Web制作・データ分析・動画制作の作品をまとめたポートフォリオサイトです。
コーディングの練習も兼ねて、HTML / CSS / JavaScript で作りました。

🔗 **公開サイト**: https://nicol9632.github.io/portfolio/

![トップページ](img/readme-top.png)

## 使った技術
- HTML / CSS（Flexbox、Grid、CSS変数）
- JavaScript（[画像の読み込み失敗時の処理など]）
- 公開：GitHub Pages
- フォント：Google Fonts（Dela Gothic One / Zen Maru Gothic / Rubik）

## ローカルでの動かし方
1. このリポジトリをクローンする
2. VS Code で開き、拡張機能「Live Server」で `index.html` を開く
   （`file://` で直接開くと、動画の埋め込みが動かないため）
